# OrderingProdject

PROJECT GOAL: create a functioning backend for a register simulation

MVP: pick random items; take in user input; compare and return true or false

Scheduled after the MVP: 
- items have unequal chances to occur
- system provides feedback other than yes or no
- system adjusts based on user input

Steps going to be taken:
- Pick Random Items from any sized list
- produce and display a full order of items (# of items can change)
- take in User Input 
- compare the user input against the order
- Pick Items from the list with given chances or occurrence
- provide the user with feedback as necessary
- have the program adjust based on what they get wrong



ideally in the future this backend is paired with a front-end GUI that cleans up the User Input process so it's not just a terminal

Tech Stack:
- Language - Java 
- Libraires - java math and array lists
